# 束线联锁控制器规程升级 · 静止输出复核（ioco）与离线测试套件

工程师在网页分别录入**旧规程**与**候选规程**（有限位置、初始位置、输入命令、
带输入或输出标签的迁移，输出可明确标记为“静止”），提交后由后端接口按
**ioco（输入输出一致性）**语义复核：纳入内部静默迁移（`tau`）与可观察静止（`δ`），
候选在旧规程可执行历史后可能给出的每项输出，都必须为旧规程在同一历史允许。

仅录入**旧规程**时，还可填写现场控制器的**最大稳定位置数**，生成一份有限的
**离线一致性测试套件（W-method）**，并将逐轮“发送命令、收到输出或静止”的
现场记录回放，确认候选控制器是否已暴露行为越界。

## 判定方法（ioco 复核）

- 对“候选位置闭包 × 旧规程位置闭包”做广度优先共归纳探索：两侧先求 `tau` 闭包，
  再沿旧规程的悬挂迹（输入、输出、`δ`）同步推进。
- 每到达一对闭包，核对 `out(候选) ⊆ out(旧规程)`；越界即不一致。
- 反例展示：按 ASCII 顺序确定的**最短历史**、两侧**逐步闭包状态集**、
  **候选输出**与**旧规程允许输出**。
- 不使用状态名对应、不做有限长度枚举、不做随机回放；
  仅位置改名而行为相同的两份规程判为一致。

## 套件生成（W-method）

1. **确定化**：对旧规程做子集构造（含 `tau` 闭包与可观察静止 `δ`）。机器状态为
   **稳定闭包**——闭包在命令轮次之外不产生任何输出（否则拒绝生成）；
   **仅在闭包内每个位置都允许某命令时才发出该命令**；每条命令之后必须恰有一个
   可观察结果（某个输出或静止 `δ`）。**若旧规程在同一命令后存在多个可观察结果，
   拒绝生成而不能任选一条**；命令后无任何可观察结果（内部静默循环）同样拒绝。
2. **最小化**：按“使能命令集、各命令观察、后继等价”合并等价状态，得 `n` 个稳定
   位置；所填上界 `m` 须满足 `m ≥ n`，否则该范围内不存在确定一致实现。
3. **套件构造**：（状态覆盖 ∪ 迁移覆盖）· 长度 ≤ `m − n` 的使能命令序列 ·
   区分后缀 `W`；互为前缀的用例只保留最长者。任何不超过 `m` 个稳定位置的
   **确定实现**，通过全部用例当且仅当它在旧规程定义的命令序列范围内与旧规程一致。
   不使用固定深度枚举、随机命令或位置名称对应。

页面展示**稳定编号**（TC-1、TC-2 …）的测试用例、**每步允许观察**，以及确定化
状态、迁移与区分后缀。套件标识由规程内容与上界寻址：相同规程重复生成标识不变，
一旦生成新套件，旧标识即**过期**。

## 现场记录回放

按用例逐轮回放现场记录（每行一轮：`命令 观察`，观察为 `!名称` 或 `δ`）：

- 全部轮次与允许观察一致 → **通过**；记录不足完整用例 → 提示**不完整**。
- 观察越界（如**静默后报警**：应静止 `δ` 却收到输出）→ 判**失败**并给出
  **首个失败轮次**（轮次、命令、允许观察、实际观察）。
- **终止用例后继续输入**、**未知标签**（未声明的命令或观察）、记录命令与用例
  不符、**过期测试标识**，均清楚拒绝并清除旧回放结果。

## 录入语法

- 位置 / 输入命令：逗号或空白分隔的名称列表。
- 迁移：每行一条 `源 -> 目标 : 标签`；`#` 开头为注释。
- 标签：`?命令` 输入（须先在输入命令中声明）；`!名称` 输出；
  `tau` 内部静默迁移；`delta` 将输出明确标记为“静止”（δ）。
  没有任何输出 / 静默 / 静止迁移的位置被视为可观察静止。
- 非法标签、悬空迁移、缺少初始位置、同一标签下重复状态声明等，
  接口将按侧别、字段与行号定位反馈，页面同时清除先前结论。

## 接口

- `GET /`：复核页；`GET /healthz`：健康检查。
- `POST /api/check`：请求体 `{"old": {...}, "candidate": {...}}`，
  每份规程含 `locations / initial / inputs / transitions` 四个文本字段。
  - 复核通过受理：`{"ok": true, "result": {"verdict": "consistent" | "inconsistent", ...}}`
  - 录入非法（HTTP 422）：`{"ok": false, "errors": [{side, field, line, message}, ...]}`
- `POST /api/suite`：请求体 `{"old": {...}, "maxStates": m}`。
  - 生成成功：`{"ok": true, "suite": {"suiteId", "stateCount", "cases", ...}}`
  - 录入非法、非确定旧规程、状态不稳定、上界过小（HTTP 422）；资源超限（HTTP 503）
- `POST /api/replay`：请求体 `{"suiteId", "caseId", "rounds": [{"cmd", "obs"}, ...]}`。
  - 回放受理：`{"ok": true, "replay": {"verdict": "pass" | "fail" | "incomplete",
    "firstFailure": {"round", "cmd", "expected", "observed", "message"} | null, ...}}`
  - 过期测试标识（HTTP 409）；未知标签、终止用例后继续输入等（HTTP 422）

## 运行（Docker / Compose）

```bash
docker compose up --build web          # 打开 http://localhost:8080
PORT=9000 docker compose up --build web  # 可配置端口
```

健康检查已内置于 Dockerfile 与 Compose（`GET /healthz`）。

## 验证（verify 服务）

```bash
docker compose up --build --exit-code-from verify verify
```

`verify` 依次执行**代码测试**（单元测试）、**构建检查**（源码编译、文件齐备、
模块导入、引擎级核对）、**HTTP 冒烟**（健康检查、复核页、经接口核对
“静默后报警”反例、一致对照、非法录入反馈、套件生成、**静默闭包后的静止通过**、
**越界报警失败**、**非确定旧规程拒绝生成**及 **HTTP 回放结果**），
完成即退出并打印退出码（0 通过 / 1 失败）。

## 本地运行（无 Docker）

```bash
python3 server.py                 # PORT=9000 python3 server.py 可改端口
python3 -m unittest discover -s tests -v
WEB_URL=http://127.0.0.1:8080 python3 verify.py
```
